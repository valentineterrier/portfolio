Spécimen publico

Specimen for the Publico Text typeface.

This project explores Publico Text (2009, Commercial Type), a typeface associated with newspapers and editorial design, through a more experimental approach.

The aim was to create an expressive web specimen using colour, contrast, scale and composition to highlight the typeface’s characteristics and graphic potential.

The result transforms a functional type specimen into an engaging visual experience.
